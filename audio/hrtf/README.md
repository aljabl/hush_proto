# MIT KEMAR horizontal HRTFs

Copyright 1994 MIT Media Laboratory. Authors: Bill Gardner and Keith Martin.
Source: https://sound.media.mit.edu/resources/KEMAR.html
Original archive: https://sound.media.mit.edu/resources/KEMAR/compact.zip

These 37 unmodified WAV files are the zero-elevation, 0–180 degree subset
of the compact dataset. Each contains 128 stereo signed 16-bit samples at
44.1 kHz, ordered left/right. Zero degrees is forward; 90 degrees is right.
The compact responses use symmetric ears; the other hemisphere is mirrored.

and cite Gardner and Martin's MIT KEMAR HRTF measurements in research reports.
